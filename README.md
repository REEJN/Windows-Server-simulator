# Serverlab

Serverlab is an interactive Windows Server 2012 R2 training game developed by **[Jenree Dandan](https://reejn.dev)**. It guides players from connecting a Ventoy USB drive and entering the BIOS through installing Windows Server, creating an Active Directory forest, adding an organizational unit and user, and sharing a folder.

**Release:** `v1.1.0`

The deployable project lives in [`server-lab/`](./server-lab/). See the [project README](./server-lab/README.md) for setup, validation, mission coverage, versioning, privacy, and scope.

## Quick start

```bash
cd server-lab
npm start
```

Then open `http://127.0.0.1:4173`.
