# Changelog

All notable changes to Serverlab are recorded here. Releases follow [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2026-09-24

### Added

- A game interface combining operating systems and data communications, with an equipment palette, network topology canvas, device inspector, event feed, missions, XP, and achievements.
- Preinstalled Windows PCs, servers, switches, routers, and firewalls with compatible Ethernet port allocation and cable validation. Each server has one-use Ventoy media in its Config panel.
- A TypeScript simulation core for device commands, IPv4 and subnet validation, topology-aware ping, DNS checks, and domain joining.
- A Windows-style PC desktop with simulated browser, Command Prompt, Control Panel, File Explorer, domain joining, and in-client mission tracking.
- Functional shared text files across reachable PCs, including remote editing, permissions checks, and saved content.
- A TP-Link-style router panel with LAN, Internet, Wireless, Status and System controls, accessible from device configuration or a connected PC browser.
- Independent saved operating system state for each server, with same-origin iframe messaging for hardware updates and network commands.
- An in-client Windows Server mission drawer, compact power controls, and responsive console scaling.
- IndexedDB persistence, localStorage fallback, migration of supported V1 progress, and JSON export/import.
- Locally bundled fonts, AI-generated hardware artwork, reduced-motion controls, and lazy-loaded topology/console views.
- Core and iframe bridge regression tests, plus a Node.js 22 GitHub Actions validation workflow.

### Changed

- Replaced the original outer dashboard with React, TypeScript, Vite, Zustand, React Flow, and Dexie.
- Preserved the detailed Windows Server JavaScript simulation in `public/client/`; production `dist/` is now generated by the build.
- Connected server USB, Ethernet, power, name, and address state to the shared lab model.
- Routed PowerShell ping through the same logical network checks used by workstation terminals and the Simulation panel.
- Expanded the guided mission from a single-server setup to a server-and-client domain lab.

### Fixed

- Retried the server-client handshake until initialization so delayed parent listeners do not leave consoles disconnected.
- Prevented unchanged hardware messages from producing repeated state updates.
- Interrupted both new installations and reinstalls when their USB media is removed.
- Preserved lab-assigned network addresses and device names during simulated server reinstallation.
- Preserved media mission credit after the one-use installer is consumed and switched subsequent boots to the installed disk.
- Added compact layouts, mobile console maximization, touch controls, and a readable/pannable server desktop mode.

### Scope

- This release remains a browser simulation. Routing, Windows applications and text-file sharing are simulated; configurable firewall policies, radio links, real internet traffic, SMB, multiplayer and cloud saves are not included.

## [1.0.1] - 2026-09-23

### Fixed

- Configured Vercel to serve the browser game as static files so the production homepage loads correctly.

## [1.0.0] - 2026-09-23

### Added

- Interactive hardware controls for the Ventoy USB drive, Ethernet cable, and server power.
- BIOS, Ventoy, and Windows Server 2012 R2 installation simulation.
- Server Manager, AD DS forest promotion, organizational unit, user, and shared-folder workflows.
- Mission tracking, field guide, local progress saving, simulated desktop apps, and PowerShell commands.
- Responsive workspace header and a simple About page with developer credit.
- Static-site configuration for Vercel deployment.
