# Device artwork

Six original, individually generated device renders support the Serverlab 2 network canvas and device palette.

| Asset | Subject | File size |
| --- | --- | ---: |
| `public/assets/computer.webp` | Desktop monitor and workstation tower | 44,292 bytes |
| `public/assets/server.webp` | Tower server with drive bays | 107,606 bytes |
| `public/assets/switch.webp` | Eight-port Ethernet switch | 49,118 bytes |
| `public/assets/router.webp` | Router with two antennas | 51,758 bytes |
| `public/assets/firewall.webp` | Security appliance with amber shield | 85,166 bytes |
| `public/assets/usb.webp` | USB-A boot drive | 72,670 bytes |

The artwork uses graphite hardware, cyan highlights, consistent three-quarter views, and flat dark backgrounds close to `#0b161d`. The files are 1,254 × 1,254 pixels, encoded as WebP at quality 85. Display with `object-fit: contain`; the generous margins preserve the silhouette in compact device tiles. The backgrounds are opaque.

Created with the built-in image generator on September 24, 2026. Each object was generated separately and inspected before format conversion. No third-party logos or product labels are included.
